# 《齿轮派对 Gear Party》游戏制作思路 + 概念图提示词

> 用途：本文档第一部分是游戏设计思路说明；第二部分是可以直接投喂给 GPT/图像模型的概念图提示词（中英双语）。
> 用同一套「风格锚点」贯穿所有提示词，保证生成的概念图风格统一。

---

## 一、游戏制作思路

### 1. 玩法拆解：从《机械狂欢》到《齿轮派对》

调研《机械狂欢（Machine Party）》后提炼出它的核心公式：

> **随机小游戏合集 + 输了就淘汰（死亡派对）+ 工业机械环境本身就是敌人 + 2~4 人互相干扰**

这个公式可以套进任何载体。微信小游戏的约束是：单机、触屏、短时、审核合规。因此做了以下适配决策：

| 原作要素 | 适配后的设计 | 原因 |
|---|---|---|
| 联机 2-4 人实时对战 | **本地轮流同屏派对**（一台手机传着玩）+ **单人挑战模式** | 免服务器，好友聚会场景同样成立 |
| 15 个随机小游戏 | 精选 6 个**触屏友好**的小游戏，每回合随机抽 1 个 | 触屏可操作性优先，量少而精 |
| 输了就死 | 扣 1 命，3 命出局 → 淘汰以「**报废**」表达 | 微信内容合规 |
| 吸烟竞速、枪械组装 | 换成「偷零件」、「装配流水线」（记忆+按序） | 去掉吸烟/枪械等敏感题材 |
| 工业机械恐怖氛围 | **可爱硬核**：暗色工厂 + 警示黄 + 圆润小机器人 | 反差萌降低血腥感，更合家欢 |

### 2. 六个小游戏的操作设计（全部触屏可玩）

| 小游戏 | 对应原作机制 | 触屏操作 |
|---|---|---|
| 💣 工坊地雷阵 | 地雷阵（探测圈） | 拖动 |
| ⚙️ 齿轮风暴 | 飞旋齿轮生存战 | 拖动躲避 |
| 🪜 爬梯狂飙 | 指令爬梯（按提示方向） | 快速滑动 |
| 🔲 图案踩格 | 图案踩格（记忆） | 点按 |
| 🔧 偷零件 | 偷食豆子（看守低头/抬头） | 按住蓄力 |
| 🏭 装配流水线 | 枪械组装（按序拼装） | 按序点按 |

### 3. 节奏与数值

- 单回合 **15~30 秒**，符合"快速轮换、传手机"的派对节奏
- 生命值 **3 命**，淘汰制带来的紧张感来自"这一把可能就是最后一把"
- **关卡难度曲线**：胜利 +1 Lv；时间变短、敌人数变多、失误容忍度下降；每 5 级换一个**阶段配色**（工厂→深海→深空→熔岩→量产），通关节奏有新鲜感
- 单人模式从"历史最高关卡 × 70%"起跳，保证重玩体验

### 4. 技术实现思路

- **原生 Canvas 程序化绘制**：所有美术（齿轮、机器人、零件、警示条纹）用代码画，零素材依赖 → 包体极小、可灰度发布
- **WebAudio 合成音效**：所有音效用振荡器合成，不依赖音频文件
- **双端同构**：微信小游戏与网页版共用一套代码，平台适配层（canvas/输入/存档/时钟）按环境切换
- **响应式页面**：手机竖屏全屏、桌面居中 + 信息面板、横屏自动适配
- **部署**：GitHub Pages 免费托管静态站，点击即玩

### 5. 美术方向（概念图都要对齐这个锚点）

- **主题**：废弃机械工厂里的淘汰赛（Industrial Scrapyard Arena）
- **风格**：卡通 3D（3D 卡通渲染 / 三渲二），圆润体型，偏可爱但带硬核机械感 —— 可参考 Fall Guys × 机械车间
- **主色板**：
  - 背景暗蓝灰 `#15171B` / `#22262D`
  - 警示黄 `#FFC400`（危险感 + 冠军感）
  - 橙 `#FF7A00`（能量/齿轮）
  - 青色 `#35D0FF`（玩家A/科技光）
  - 玩家四色：青 `#35D0FF`、橙 `#FF9F1C`、绿 `#7EE081`、品红 `#FF5CA8`
- **标志元素**：黄黑警示斜条纹、外露齿轮、管道、铆钉、探照灯、浓淡不一的工业雾气
- **光线**：车间顶灯 + 体积光 + 金属反光，暗部压暗、警示色发光

## 三、使用建议

1. **一致性优先**：先按 #1 主视觉生成并定稿风格，之后所有场景图都加同一段「通用风格锚点」，避免中途风格漂移。
2. **比例按用途选**：图标/头像用 1:1，关卡场景用 16:9，竖屏背景用 9:16，分享图用 1.91:1。
3. **负面提示**：一律附加 `no text, no watermark, no letters, no logo, no UI, no blur, no deformed hands`。
4. **版权注意**：本游戏为原创 IP，提示词特意避开了《机械狂欢》的角色与美术元素，只保留"工业机械 + 生存淘汰"的玩法氛围。
5. **批量生成**：可以把 11 条英文提示词一次性贴给 GPT，让它逐条出图，再挑风格最统一的做后续迭代。
