# 齿轮派对 Gear Party

一款参考「死亡派对」（Death Party）类型玩法、**完全原创实现**的机械工厂淘汰小游戏。
玩法灵感来源于《机械狂欢》（Machine Party，恶魔轮盘制作人 Mike Klubnika 的多人派对游戏）的核心理念：
**随机小游戏 + 输了就淘汰 + 工业机械环境**。本作针对微信小游戏场景做了单机化适配。

> ⚠️ 合规说明：本项目不包含原作的任何素材/名称/音效/代码，游戏名、美术（全部程序化绘制）、音效（WebAudio 合成）均为原创；
> 内容上已做合规处理：无吸烟、无枪械、无血腥，淘汰以「报废」表达，符合微信小游戏审核方向。

## 玩法

### 两种模式

| 模式 | 说明 |
|------|------|
| ⚡ 单人挑战 | 3 条命，随机连闯小游戏，赢了加分（连胜加成），输了扣命，命尽结束，冲最高分 |
| 👥 本地派对（2-4 人） | 一部手机轮流同屏对战：每回合随机一个小游戏，全员各玩一次后排定名次，**最低分者扣 1 命**（并列并列扣），命尽淘汰，最后存活者获胜 |

### 六个小游戏（每回合随机）

| 小游戏 | 规则（参考自《机械狂欢》对应关卡） | 操作 |
|--------|------|------|
| 💣 工坊地雷阵 | 对应「地雷阵」：穿过暗雷区抵达终点，靠近的地雷会显形 | 拖动机器人移动 |
| ⚙️ 齿轮风暴 | 对应「飞旋齿轮生存战」：坚持到倒计时结束 | 拖动躲避飞旋齿轮 |
| 🪜 爬梯狂飙 | 对应「指令爬梯」：按提示快速滑动正确方向，按错下滑、3 次失误坠入滚筒 | 滑动对应方向 |
| 🔲 图案踩格 | 对应「图案踩格」：记住亮起的格子并踩中，踩错 3 次板块下沉 | 点按格子 |
| 🔧 偷零件 | 对应「偷食豆子」：趁检修机器人低头看报时按住偷零件，它抬头瞬间收手必被抓 | 按住零件蓄力偷取 |
| 🏭 装配流水线 | 对应「枪械组装/魔方打砖块」的记忆+按序机制：记住图纸顺序，按序点击零件组装 3 台机器 | 点按零件 |

## 运行

### A. 微信开发者工具（正式版）
1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
2. 打开工具 → 导入项目 → 选择本项目目录 `gear-party`；
3. 项目类型选 **小游戏**，AppID 选择**测试号**（或你的小游戏 AppID）；
4. 编译运行即可。竖屏、免素材、零依赖（仅原生 Canvas + WebAudio）。

### B. 浏览器快速预览（自适应）
直接用浏览器打开 `index.html` 即可（支持鼠标/触屏，滑动手势=按住拖动或滑动）。
页面已做全平台响应式适配：手机竖屏全屏展示、桌面/平板宽屏自动居中并显示玩法说明面板、横屏自动适配，Canvas 按实际容器尺寸渲染。

## 项目结构

```
gear-party/
├─ game.js                  # 微信小游戏入口（require 各模块后启动）
├─ game.json                # 小游戏配置（竖屏）
├─ project.config.json      # 开发者工具工程配置
├─ index.html               # 浏览器预览入口
└─ js/
   ├─ config.js             # 全局配置：尺寸/配色/小游戏注册表
   ├─ platform.js           # 双端平台层：canvas/输入/存档/rAF 看门狗
   ├─ audio.js              # WebAudio 合成音效
   ├─ render.js             # 程序化绘制：齿轮/机器人/零件/粒子等
   ├─ players.js            # 玩家数据与排名
   ├─ flow.js               # 主流程状态机：菜单/选人/回合/结算/淘汰/排行榜
   ├─ difficulty.js         # 关卡难度曲线：等级→时间/速度/数量/阶段配色
   └─ minigames/
      ├─ common.js          # 小游戏公共组件（HUD/倒计时）
      ├─ minefield.js       # ① 工坊地雷阵
      ├─ gearstorm.js       # ② 齿轮风暴
      ├─ ladder.js          # ③ 爬梯狂飙
      ├─ patternpad.js      # ④ 图案踩格
      ├─ stealparts.js      # ⑤ 偷零件
      └─ assembly.js        # ⑥ 装配流水线
```

## 扩展：加一个新小游戏

1. 在 `js/minigames/` 下新建 `xxx.js`，实现统一接口：

```js
GP.MG.xxx = { create: function () { return {
  update: function (dt) {}, draw: function () {},
  onDown: function (x, y) {}, onMove: function (x, y) {},
  onUp: function () {}, onSwipe: function (dir) {},
  // 结束时设置：
  // this.result = { win: true/false, msg: '...', score: 123 }
}; } };
```

2. 在 `js/config.js` 的 `CFG.MG` 注册元信息（id/名称/图标/描述/时长）；
3. 在 `game.js` 与 `index.html` 中引入该文件。

## 设计参数速查

- 全局配色/尺寸/小游戏清单：`js/config.js`
- 各小游戏的时长、速度、数量等平衡参数：对应 `js/minigames/*.js` 文件顶部常量
- 玩家命数：`CFG.SOLO_LIVES` / `CFG.PARTY_LIVES`
